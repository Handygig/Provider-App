# Provider App 📱

A modern, responsive, and robust **Service Provider Mobile Application** built with Flutter. This application is part of the Service Booking System and serves as the dedicated portal for service providers (handymen, technicians, etc.) to register, select services, manage their profile, and receive jobs.

---

## 🚀 Key Features

* **Multilingual Support**: Interactive Language Selection Screen allowing users to select their preferred language.
* **OTP Authentication**: Secure login flow using Firebase OTP Verification.
* **Onboarding & Registration Wizard**:
  * **Provider Details**: Capture basic personal and professional info.
  * **Living/Location Details**: Form to capture the provider's operational area.
  * **Service Assignment**: Dynamic UI to assign services/skills to the provider.
* **Account Review System**: A dedicated "Under Review" state screen informing the provider that their application is being verified by admin staff.
* **Responsive UI Design**: Built using `flutter_screenutil` to ensure pixel-perfect rendering across various mobile device dimensions (designed for `430x932` base resolution).
* **Modern Design & Animations**: Features a clean material design theme, custom SVG icons, and smooth transitions.

---

## 🛠 Tech Stack

* **Core Framework**: [Flutter SDK](https://flutter.dev) (v3.12.1+) & Dart
* **Authentication**: [Firebase Authentication](https://firebase.google.com/) (OTP-based Verification)
* **API / Networking**: [Dio](https://pub.dev/packages/dio) for optimized HTTP networking
* **State Management / Model Helpers**: [Equatable](https://pub.dev/packages/equatable) for value-based equality comparisons
* **UI & Styling**: 
  * [Google Fonts](https://pub.dev/packages/google_fonts) for typography (`Outfit` / `Inter`)
  * [Flutter ScreenUtil](https://pub.dev/packages/flutter_screenutil) for screen adaptation and responsive scaling
  * [Flutter SVG](https://pub.dev/packages/flutter_svg) for vector graphics rendering
  * [Country Flags](https://pub.dev/packages/country_flags) for locale flag representations

## ⚙️ Getting Started & Setup

Follow these steps to set up and run the project locally.

### Prerequisites

Ensure you have the following installed on your machine:
* **Flutter SDK** (v3.12.1 or newer): [Flutter Installation Guide](https://docs.flutter.dev/get-started/install)
* **Dart SDK** (v3.0.0 or newer)
* **Android Studio** (for Android Emulator/SDK) or **Xcode** (for iOS Simulator, macOS only)
* **Git**

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Service-Booking-System/Provider-App.git
   cd Provider-App
   ```

2. **Get Dependencies**
   Fetch all the package dependencies specified in `pubspec.yaml`:
   ```bash
   flutter pub get
   ```

3. **Firebase Configuration Setup**
   * If you want to connect to a custom Firebase project, run:
     ```bash
     flutterfire configure
     ```
   * Ensure that the generated/existing `lib/firebase_options.dart` and `firebase.json` align with your target Firebase Project.

4. **Run the Application**
   * Connect a physical device or start an emulator/simulator.
   * Run the app in development mode:
     ```bash
     flutter run
     ```
